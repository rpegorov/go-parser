Test project for [go-parser](https://github.com/rpegorov/go-parser) library.
Test optimised parse big data (ower 1 billion records) from dpa-server.


1 Потребление памяти среднее 300 мб. Оптимально для работы 1 гб с учетом просадок.
2 Для получения данных через интернет параллельно обрабатывается не более 50 запросов (оптимально 5-25), поскольку
пул соединений с базой данных ДПА всего 100 соединений.
3 Таймаут соединения с АПИ ДПА должен быть не менее 60 секунд. Оптимально 120-240.
4 Для старта процесса парсинаг вначале необходимо авторизоваться в АПИ ДПА - {{server}}/login
5 Запрос данных по временым рядам с интервалом 3 дня, в противном случае слишком долго ждать ответа от сервера
даже при таком запросе ошибка получения тела ответа, либо ответ приходит не кореектный (без ошибки) либо
вообще не приходит и пустое тело - Ошибка получения данных: ошибка чтения тела ответа: context deadline exceeded
(Client.Timeout or context cancellation while reading body)
